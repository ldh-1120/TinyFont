# TinyFont

**A tiny pixel font for games and interfaces.**

TinyFont is a minimal, proportional pixel font designed to remain readable at very small sizes.
Built pixel by pixel, with simplicity and clarity in mind.

## Features

- Minimal pixel-based design
- Uppercase and lowercase Latin letters
- Numbers and punctuation
- 99 supported characters
- TrueType Font (.ttf)
- Free for personal and commercial use

## Installation

**Windows**

1. Download and extract the release archive.
2. Right-click `TinyFont-Regular.ttf`.
3. Select **Install**.

**Games & Applications**

TinyFont can be embedded in games, applications, and websites under the terms of its license.
For pixel-perfect rendering, use appropriate integer scaling and disable smoothing where possible.
